# Kestrel DB

An embedded-friendly key-value store with batch writes and an asynchronous client.

- Current release: 3.2.0
- Documentation: see the `docs/` folder
- Core licence: Apache-2.0

## Enterprise plugin

Replication and audit features are provided by a separate enterprise plugin. It is available under a separate commercial agreement; contact the sales address on the project site.
