# Rubric: creative quality

The automated checks for `creative-short-script` verify the production constraints: timing, lengths, banned words, the call to action, the loop and the subtitle file. They say nothing about whether anyone would watch the result. Use this rubric for that. It is scored by a person, or by a judge model given the brief, the script and this rubric — never the name of the configuration that produced it.

Score each criterion 0, 1 or 2 and quote the line that justifies it.

| # | Criterion | 0 | 1 | 2 |
|---|---|---|---|---|
| C1 | **Hook** | Generic question that fits any product | Specific to the game, no tension | Specific and makes the viewer want the next beat |
| C2 | **One idea** | Several messages compete | The stated idea is present with distractions | Every beat serves "the river does the moving, you only bend it" |
| C3 | **Show, don't tell** | Visuals restate the voiceover | Some beats add information visually | Visuals carry the mechanic; words add what images cannot |
| C4 | **Rhythm** | Beats of equal weight | Some variation | Pace changes with content; the pause lands where it should |
| C5 | **Tone** | Hype or salesy | Neutral | Calm and curious, as the brief asks |
| C6 | **Call to action** | Bolted on | Clear, slightly abrupt | Follows naturally from what was shown |
| C7 | **Loop** | Last caption repeats the first with no visual link | Loop works textually | The final image leads back into the opening shot |
| C8 | **Originality** | Could be any puzzle game | One distinctive image or phrase | Memorable, and unmistakably this game |

**Total: 0–16.** Report the per-criterion scores, not only the total.

## Procedure

1. Blind the submissions.
2. Score each submission alone before ranking.
3. For a judge model, take three independent judgements and report the median and the spread.
4. A script that fails a hard constraint is reported as failing, whatever its rubric score. Craft does not excuse a missed limit.

Status in this repository: the rubric is provided; no rubric scores have been produced or published with version 1.0.0.
