Agent Skill · prompt framework · benchmark

A working method for AI agents.

DIAVLO MIND makes a model write down the requirements, pick an effort level, look before it acts, test what it built and report with evidence. One skill for Claude Code, Codex, Gemini CLI and any LLM.

Install

Two commands. No dependencies.

Plain-text instructions plus optional Python tools that use the standard library only. Nothing is compiled and nothing is downloaded at run time.

Claude Code, Codex, Gemini CLI, Antigravity

The installer copies the skill where your agent looks for skills.

git clone https://github.com/Nikolai-coder/diavlo-mind
cd diavlo-mind
python scripts/install.py claude-code
# or: codex | gemini-cli | antigravity

Claude Code plugin

The repository is also a plugin marketplace: one skill and eight subagents.

claude plugin marketplace add Nikolai-coder/diavlo-mind
claude plugin install diavlo-mind@diavlo

Any chat model or API

Paste one of four system prompts, from 1,500 characters up, or run the bundled orchestrator.

# custom GPTs, project instructions
prompts/system/diavlo-mind-compact.md
# any API, with your own test command
python scripts/dm_orchestrate.py --help
What is inside

An operating procedure, not a personality prompt.

Every procedure describes actions another agent can perform and an outsider can observe: read this, run that, write this down, report in this form.

10rules, fingerprinted so they cannot change unrecorded
4effort modes: fast, standard, deep, autonomous
20step-by-step procedures, loaded on demand
8agent roles with separated powers
4portable system-prompt tiers
8benchmark tasks with hidden checks
Measured, not promised

96 benchmark runs. Here is what happened.

Eight tasks, three trials each, with and without the framework, scored by hidden checks. Every run is published.

  • On the newer model there was nothing left to gain on this suite, and the framework cost 28% more.

Questions

Short answers.

Does it make a small model as capable as a large one?

No. Instructions change what a model is asked to do, not what it can do. The table above is the honest size of the effect, including the case where there was none.

Is it a leaked system prompt or a jailbreak?

No. It was written from scratch as observable procedures. It does not ask a model to reveal private reasoning and does not try to remove any safeguard.

Do I need Python?

Only for the optional tools. The skill and the prompts are plain text.

How do I know my copy is intact?

Run python scripts/validate.py, python -m unittest discover -s tests and python evaluation/selftest.py.
